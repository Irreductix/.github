# Irréductix

**Des outils libres pour le service public. Faits par ceux qui s'en servent.**

Irréductix est un collectif informel qui construit les logiciels dont l'hôpital
public a besoin, et les publie sous licence libre. Pas d'adhésion, pas de
cotisation, pas d'offre commerciale. Tout s'installe chez vous, sans service
externe.

## Les outils

| Outil | Le problème qu'il règle | Pour commencer |
|---|---|---|
| [**Registris**](https://github.com/irreductix/Registris) | Prouver à un auditeur, matricule par matricule, qui a obtenu quel accès, quand, à la demande de qui et sur quelle pièce. Registre des habilitations et coffre à preuves d'audit pour les établissements publics de santé. | [Installateur Windows](https://github.com/irreductix/Registris/releases/latest), [Présentation](https://irreductix.fr/outils/registris) |
| [**referentiels-sante**](https://github.com/irreductix/referentiels-sante) | Ouvrir FINESS, la CCAM, la CIM-10, la base des médicaments, la NABM, la LPP, les UCD ou les tarifs GHS dans Excel. Conversion en CSV et JSON depuis la source officielle. | [FINESS en CSV du mois](https://irreductix.fr/telecharger/finess.zip), [Présentation](https://irreductix.fr/outils/referentiels-sante) |

## Contribuer

Pas besoin d'être développeur : connaître le terrain suffit souvent.

- **Un écart, un bug** : un ticket sur le dépôt concerné, avec les étapes pour
  reproduire. Jamais de donnée réelle.
- **Une heure devant vous** : les tickets
  [`good first issue`](https://github.com/search?q=org%3Airreductix+label%3A%22good+first+issue%22+is%3Aopen&type=issues),
  chacun avec le profil attendu.
- **Une question** : l'onglet Discussions de chaque dépôt.
- **Un besoin d'outil** : <https://irreductix.fr/contribuer#proposer>

Sans compte GitHub : <contact@irreductix.fr>. Site : <https://irreductix.fr>
